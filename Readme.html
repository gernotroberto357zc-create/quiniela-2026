📌 Descripción General

La Quiniela Mundial 2026 es una plataforma web full-stack diseñada para la gestión de apuestas deportivas amistosas. Permite la participación de usuarios en tiempo real, con un sistema de puntos automatizado y un panel de control para la administración de resultados.

🛠️ Stack Tecnológico

Frontend (Interfaz de Usuario)

React 18 Vite Tailwind CSS Lucide Icons

Backend & Database (Infraestructura)

Supabase (BaaS) PostgreSQL SQL Triggers Row Level Security

📂 Estructura del Proyecto

  • /src/lib/supabase.js: Configuración del cliente para la conexión con el backend.
  • /src/App.jsx: Componente principal que contiene la lógica de navegación, vistas de partidos y ranking.
  • Tablas en Supabase:
    • partidos: Datos de los encuentros y resultados oficiales.
    • pronosticos: Votos de los usuarios (Relación 1:N con usuarios).

🔐 Seguridad y Lógica de Negocio

El proyecto implementa medidas de seguridad críticas:

  • Protección de Apuestas: Los usuarios no pueden votar en partidos cuya fecha/hora sea anterior a la actual.
  • Integridad de Datos: Se utilizan políticas RLS en Supabase para asegurar que un usuario solo pueda insertar o modificar sus propios pronósticos.
  • Cómputo en Servidor: El ranking se calcula mediante una función SQL almacenada para evitar manipulaciones en el cliente.
